# risk_margin(入力の切り替えの確率を含めたマージン、オフライン評価)

実機の実験ではない。11/14 夜のランダムの実験(`experiments/20261114_validate_random`)のデータを使うオフライン評価。`scripts/eval_risk_margin.py`。

## 動機

干渉がない(c = 0)と、提案手法の σ は一定で、動的マージン 2σ + δ は固定と同じになる(7.3 節)。一方、予測の誤差の大半は、30 秒以内に負荷やファンが切り替わる区間から生じ、σ はそれを含まない(切り替えの区間の超過率 21〜34%)。
11/14 に「今すぐ最大の負荷に上がる」と仮定してマージンを足したら 6〜8℃ と過剰だった。その中間として、切り替えが起きる確率と、切り替わり方の分布をデータから見積もり、予測の誤差の分布に入れる。

## 方法(2026-11-22、結果を見る前に決めた)

時刻 k の 30 秒先(m = 6 ステップ先)の温度の誤差を、次の混合分布で表す。

- 確率 1 − p:切り替えなし。誤差 ~ N(0, σ²)(σ はカルマンフィルタの予測の標準偏差、今と同じ)
- 確率 p:先読みの間のどこか(ステップ s = 0〜m−1 のどれか、等確率)で、負荷とファンが (u', f') に切り替わる。誤差 ~ N(J, σ²)、J = (b (u' − u_k) + e (f' − f_k)) Σ_{i=0}^{m−1−s} a^i
- p:同定区間で「k から m ステップの間に切り替え(フェーズの境界)がある」割合
- (u', f') の分布:同定区間のフェーズの切り替えで、切り替え後の (負荷, ファン) の経験分布(今の状態によらない。データが少ないため)
- マージン M_k = (混合分布の 97.7% 点)+ δ(δ = 0.5℃、今と同じ)。今の手法は p = 0 の場合にあたる(97.7% 点 = 2σ)

パラメータ(a, b, e, d、σ の元になる qT と R)は、7 章と同じく前半で同定したもの(`results/eval/params.json`、自ノードのみ、c = 0)。p と (u', f') の分布も前半だけから求める。評価は後半だけ。

比べるもの(後半、3 台):今の提案(2σ + δ)/ Self-only + 固定(前半の誤差の 97.7% 分位点)/ 今回の方法。指標は平均マージン、超過率(全区間・入力一定・切り替え)。

判定(事前に決める):今回の方法が「全区間の超過率が 2.3% の 2 倍(4.6%)以下」かつ「平均マージンが固定マージンより小さい」なら、σ が一定でも動的マージンに意味がある、と言える。どちらかを満たさなければ、その結果をそのまま書く。

注意:この評価はランダムな負荷のデータ(切り替えの確率と分布が一定)に対するもの。実際の負荷では切り替えの確率と分布は違う。
