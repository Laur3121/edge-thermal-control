# 2026-11-13 ラックでの熱干渉の確認

## 条件

- 日時:2026-11-13 14:36〜15:09(温度が落ち着くまでの待ち 約15分 + 基準 3分 + 負荷 10分 + 休み 5分)
- 設置:19インチラックのブレード型マウント(基板を縦に立てて横に並べる形)の上段。空き3スロットに左から raspi1(A)| raspi2(B)| raspi3(C)。上段右端に金属ケース入りのノード、下段に4台(いずれもアイドル、OS の自動ファン制御)。ラックは前後・上が大きく開いた形
- 給電:PoE、PoE+ HAT 装着
- ファン:3台とも OFF(node_agent が制御)
- 負荷:A だけ `stress-ng --cpu 2`(CPU 使用率 約50%)を10分
- CPU ガバナ:performance(1.8 GHz 固定)
- 室温:SwitchBot。ラックの上=温湿度計1、左=3、右=2、ハブ2 は離れた場所(`raw/ambient.csv`)
- 14:34 に一度始めたが、温湿度計を置き直すため待ちの段階で中断した(`20261113_rack_interference_aborted`、PC 上のみ)
- シナリオ:`scripts/scenarios/rack_interference.json`
