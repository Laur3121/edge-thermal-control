# 2026-11-13 同定用ステップ実験

## 条件

- 日時:2026-11-13 15:10〜17:24(温度が落ち着くまでの待ち 約6分 + 本体 約2時間8分)
- 設置:ラック上段、左から raspi1(A)| raspi2(B)| raspi3(C)。`20261113_rack_interference` と同じ配置
- 給電:PoE、PoE+ HAT 装着。CPU ガバナ performance
- 負荷とファン(A だけ。B・C はアイドル・ファン OFF。シナリオ `scripts/scenarios/step_identify.json`)
  - part1:A を 2コア負荷のまま、ファン ON 5分 / OFF(75℃ まで)を3回
  - part2:A のファン ON で、負荷 2コア 15分 → 休み 10分 → 1コア 15分 → 休み 10分
  - part3:A のファン OFF で、76℃ までの負荷パルスを3回(休み 8分)
- 室温:温湿度計(ラックの上=1、左=3、右=2)とハブ2(室温)。**実験中に室温が 23.7 → 22.1℃ と 1.6℃ 下がった**
- スロットリング:なし(最高 76.4℃)

## 同定の方法(`scripts/identify_step.py`)

- A の 1 秒ログを 5 秒平均にし、**室温からの上昇分 θ = T − T_amb** でモデルを立てる(RC モデルの形:θ_{t+1} = a θ + b u + e f + d)
- 同定は part2・part3、検証は part1(同定に使っていない区間)
- 予測は Δ = 30 秒先。負荷は「今の値が続く」と仮定、ファンは制御側が決める入力なので将来の値を既知とする

## 結果(`results/identify.json`、`results/identify_validation.png`)

ファンの扱い(docs/parameters.md の案A・案B)を比べた:

| | 1ステップ RMSE | 30秒先 RMSE | 30秒先 MAE | 備考 |
| --- | --- | --- | --- | --- |
| 案A(ファン OFF/ON でパラメータ切替) | 0.48℃ | 1.87℃ | 1.52℃ | ファン ON 後の冷え方が速すぎる |
| **案B(+ e·f の加算項)** | **0.42℃** | **1.42℃** | **0.75℃** | 実測によく合う → **採用** |

案B のパラメータ(dt = 5 秒、温度は室温からの上昇分):

| 記号 | 値 | 意味 |
| --- | --- | --- |
| a | 0.927 | 時定数 τ = −dt/ln a ≈ **66 秒**(IPSJ 時の「約 60〜66 秒」と一致) |
| b | 1.915 | 負荷 1(=100%)あたりの寄与。**正**(IPSJ 時は負で不自然だった) |
| e | −1.407 | ファン ON の効果(1 ステップあたり) |
| d | 2.719 | 待機電力による項 |

物理的な確認(案A の値から):

- ファン OFF の時定数 約70秒、ファン ON 約33秒。ファンで熱抵抗が下がり、速く冷える
- 2コア負荷(u = 0.5)の定常温度上昇:ファン OFF で室温 +54℃(室温 23℃ なら約 77℃)、ファン ON で +30℃(約 53℃)。実測(OFF で約 76℃ に向かって上昇中、ON で 53〜54℃)と合う
- ファンを入れると温度は**5 秒以内に下がり始める**(図の急な落ち込み)→ ファンの応答時間 < 5〜10 秒。Δ = 30 秒は「ファンの応答時間 < Δ < 時定数 66 秒」を満たす

観測ノイズ:1 秒値のばらつきの分散 0.34℃²(センサの刻みは 0.487℃)。5 秒平均では約 0.07℃² 程度(IPSJ 時の R = 0.077 と同程度)。

## 干渉(参考)

A の温度を隣接入力にして B・C を同定すると、どちらも c ≈ 0.02〜0.03、「A が 1℃ 上がると定常で約 0.1℃」と**B と C で同じ**。すぐ隣の B だけに効く干渉ではなく、室温の低下など全体に共通の変化を拾っているだけと考えられる。`20261113_rack_interference` の結論(ラックでは干渉はほぼない)と一致。

## 気づいたこと

- ファン ON 直後の急な落ち込み(数秒で数℃)と、その後のゆっくりした低下の 2 段階がある。1 次の RC モデルでは表しきれず、案B の加算項が近似としてよく効いている。2 次(2 つの時定数)モデルは今後の課題
- ラックの上の温湿度計1は A の負荷に合わせて 27〜29℃ まで上がる(排気が上に抜けている)
