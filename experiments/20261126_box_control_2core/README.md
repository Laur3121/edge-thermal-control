# box_control_2core(囲いあり:負荷を下げたファン制御の比較)

2026-11-26 朝。条件・指標・判定は、この README を書いた時点(実行前、7:25)で決めた。結果は外れても全部書く。生ログは編集しない。

## なぜやるか

`20261125_box_control` の第 2 部(囲いあり、8 台同時、4 コアを含む負荷パターン)では、常時 ON でも最高 80.3℃ で、ファンに余裕がなかった。予測を使う方式としきい値は、どれも 80℃ を超えた(提案 1372 秒、自ノード 1324 秒、しきい値 1019 秒、16 回の合計)。予測で比べる前に、ファンが 80℃ を守れる余裕のある条件で比べる必要がある(レオ、11/26 朝:「2 コアで回して」)。

## 条件(`20261125_box_control` 第 2 部との違いは負荷と方式だけ)

- 配置・囲い:同じ(10 インチラック 2 段 × 4 列、段ボール箱で上・左右・後ろを覆い、正面と下は開いている。昨夜から変えていない)。8 台とも PoE+ HAT、ON は段階 4
- 負荷パターン(20 分):コア数を半分にした。1 コア 2 分 → **2 コア 6 分** → 0 コア 3 分 → **2 コア 5 分** → 1 コア 2 分 → **2 コア 2 分**(昨夜は 4・4・2・4 だった所を 2・2・1・2 に)。8 台同時に同じパターン。その後 12 分休み(負荷 0・ファン OFF)
- 方式:しきい値(75℃ ON・70℃ OFF)/自ノードの予測 + 固定マージン/提案(KF + H、M = 2σ + 0.5)。**常時 ON は外す**(稼働率は 100% で決まっていて、昨夜のデータがある)
- 2 巡、順番はランダム(seed 20261126):1 巡目 しきい値 → 提案 → 自ノード、2 巡目 自ノード → 提案 → しきい値
- 制御のパラメータ:昨夜と同じ `scripts/control_params_box.json`(11/25 午後の囲いありのデータで同定)。変えない
- シナリオ:`scripts/scenarios/gen_box_control.py --ctrl-only --half-load --conds threshold selffixed proposed --seed 20261126` → `box_control_2core.json`
- 見張り:`box_watchdog.py --limit 50`(箱の中の温度計 1〜3 のどれかが 50℃ で止める)

## 指標と判定

指標は昨夜の第 2 部と同じ(`scripts/analyze_box_control.py`):ファン稼働率、80℃ を超えた時間、最高温度、強制 ON の時間、最低クロック、ON/OFF の回数。

- 予測を使う方式(提案・自ノード)は、80℃ 超過 0 のまま、しきい値より稼働を減らせたか
- 提案は自ノードの予測より「同じ安全で稼働が少ない」か「同じ稼働でより安全」か。差が 2 巡のばらつきより小さければ「差なし」
- 予想(Claude):3 方式とも 80℃ 超過はほぼ 0。稼働はしきい値・予測ともに 30〜50%。提案と自ノードの差は小さい(c が 0.006〜0.046 と小さいため。11/14 の開いたラックと同じ傾向)

## 実行の記録

- 7:16 開始(`experiments/box_control_2core_run.log`)。8 台とも etc-agent を再起動(全台 `--fan-mode poe`)してから。見張り `box_watchdog.py --limit 50` も同時に起動。開始時の温度は 54℃ 前後(ファンは OS の自動制御で回っていた → OFF にして落ち着き待ち)。終了見込みは 11 時ごろ

- 8:40 注:この実験は `control_params_box.json`(6 台のファンの効きが借り物で誤っていた)のまま回っている。途中では変えない。次の d90 からは `control_params_box2.json`(`20261126_box_control_d90/README.md` の「実行前の変更」)
- **8:00 中断**(SIGINT、レオと相談して決定)。制御のパラメータ `control_params_box.json` は 6 台のファンの効きが借り物で誤っていた(`docs/model-review-2026-11-26.md`)。提案と自ノードの予測はこの誤ったモデルで回るため、続けても比較に使えない。中断時点で 1 巡目のしきい値の途中(c1_threshold_s4)。しきい値の部分は参考として残す。直したパラメータ(`control_params_box2.json`)で後でやり直す
