# ar_baseline(温度の履歴だけから予測する AR モデルとの比較、オフライン評価)

実機の実験ではない。11/14 夜のランダムの実験(`experiments/20261114_validate_random`)のデータ。`scripts/eval_ar_baseline.py`。

## 動機

関連研究の Coskun ら(ISLPED 2008)は、温度の履歴だけから ARMA モデルで数ステップ先を予測して先回りの制御をした。負荷やファンの入力を使わない、データだけの予測である。7 章の予測の比較(Self-only、KF)に、この種の予測を比較相手として加え、「負荷とファンを入力に持つ物理モデル」の意味を確かめる。

## 方法(2026-11-22、結果を見る前に決めた)

- 予測するもの:5 秒平均の温度(室温からの上昇分 θ)の 30 秒先(6 ステップ先)。7 章と同じ
- AR モデル:θ の差分 Δθ_t = θ_t − θ_{t−1} を、過去 p 個の差分で表す AR(p)(定数なし)。差分にするのは、温度の水準が負荷とファンで大きく変わり、水準そのものの AR では平均に引き戻されるため。6 ステップ先は再帰的に予測した差分を足して求める
- 次数 p は 1〜12 から、前半(同定区間)の 1 ステップ先の残差で AIC が最小のもの。係数は前半で最小二乗
- 比べるもの:AR(履歴のみ)/ Self-only(負荷・ファンを入力、今の値が続くと仮定)/ KF(H なし)。後者 2 つは 7 章と同じ前半の同定値
- 指標:後半の MAE と RMSE。全区間・入力一定・切り替え(7 章と同じ区分)。3 台(A、B、C)
- 予想:入力一定の区間では AR も近い精度になるが、切り替えの直後(入力が変わったあと)の追従は、入力を知っている物理モデルの方が速い。切り替えをまたぐ区間はどれも外れる

予想が外れても全部書く。
