# delay_sweep(冷却の遅れを 0・15・30・60 秒と振って、予測が効く境目を見る)

2026-11-27 12:10。条件・判定・予想は、この README を書いた時点(実行前)で決めた。結果は外れても全部書く。生ログは編集しない。

## 本筋のどこを支えるか

結果 ③「予測が要るのは冷却が遅いとき。何秒以上遅ければ入れるべきか」。予備審査(11/27)の指摘を受けた 12 月の本筋の実験(docs/tasks.md 冒頭)。今は遅れ 0 秒(open_control、差なし)と 60 秒(open_delay60、80℃ 超え 3 割減)の 2 点しかないので、15・30 秒を足し、0・60 秒も同じ日にやり直して 1 本の曲線にする。

## 方法

- `20261126_open_delay60` と同じ仕組み:制御用 PC が決めたファンの ON/OFF の指令を d 秒あとにノードへ送る(`fan_delay_s`)。ノードの強制 ON(82℃)は遅らせない
- 提案は遅れを知っている(先読み 30 + d 秒、出した指令を予測に入れる)。しきい値は今の温度だけを見る
- 遅れ d = 0・15・30・60 秒。各 d で しきい値/提案 × 2 巡(巡ごとに順番はランダム)
- 遅れの順番はランダム(seed 20261127):60 → 15 → 30 → 0
- 配置:囲いなし、10 インチラック 2 段 × 4 列、8 台とも PoE+ HAT、ON は段階 4
- 負荷:open_control・open_delay60 と同じ 20 分のパターン(1 → 4 → 0 → 4 → 2 → 4 コア)、8 台同時、12 分休み
- パラメータ:`scripts/control_params_open.json`(open_delay60・open_control と同じ)
- シナリオ:`gen_box_control.py --ctrl-only --conds threshold proposed --seed 20261127<d> --fan-delay d` → `scripts/scenarios/delay_sweep_d{0,15,30,60}.json`(各約 2.2 時間、合計約 9〜10 時間)
- 出力:`experiments/20261127_delay_sweep/d{00,15,30,60}/`
- **判定は r5 を除く 7 台**(ファンの不調、11/26)。8 台の値も書く

## 指標と判定

指標は `analyze_box_control.py` と同じ。各 d で、7 台・2 巡の合計の 80℃ を超えた時間(しきい値 S_d、提案 P_d)と稼働率。減少率 R_d = 1 − P_d / S_d(S_d が 60 秒未満の d は「差を比べられない」とする)。

- **予想どおり**:R_d が d とともに増える(R_0 ≤ R_15 ≤ R_30 ≤ R_60。隣どうしの逆転は 0.1 以内なら許す)、かつ R_60 ≥ 0.2、かつ各 d で提案の稼働がしきい値の +10 ポイント以内
- **外れ**:それ以外。どこが違ったかを書く
- 境目:R_d が初めて 0.2 を超える d を「予測を入れる意味がある遅れ」とする(暫定の定義。0.2 は open_delay60 の 0.32 と open_control の約 0 の間で、測る前に決めた)
- 予想(Claude):d = 0 と 15 は S_d が小さく差なし、d = 30 で R ≈ 0.1〜0.3、d = 60 で R ≈ 0.3(昨夜と同程度)。稼働は提案が 0〜5 ポイント多い

## 結果(2026-11-28 21 時、Claude。`analyze_box_control.py` → 各 d の results/)

r5 を除く 7 台・2 巡の合計:

| 遅れ d | しきい値 稼働 / 80℃ 超え S_d | 提案 稼働 / 80℃ 超え P_d | R_d = 1 − P/S | 巡ごとの 80℃ 超え(しきい値 / 提案) | 強制 ON(しきい値 / 提案) |
|---|---|---|---|---|---|
| 0 | 53.8% / 95 秒 | 55.5% / 94 秒 | 0.01 | 45・50 / 46・48 秒 | 1 / 16 秒 |
| 15 | 54.3% / 595 秒 | 55.8% / 397 秒 | 0.33 | 319・276 / 193・204 秒 | 129 / 88 秒 |
| 30 | 53.2% / 1189 秒 | 55.7% / 735 秒 | 0.38 | 591・598 / 363・372 秒 | 264 / 176 秒 |
| 60 | 55.1% / 2437 秒 | 58.0% / 1718 秒 | 0.30 | 1206・1231 / 864・854 秒 | 617 / 480 秒 |

r5(ファン不調)はどの条件でも最高 85.7〜86.7℃。

**判定:予想どおり**
- R_d が d とともに増える:0.01 → 0.33 → 0.38 → 0.30。隣どうしの逆転は 60 秒の −0.08 だけで、許す範囲(0.1 以内)○
- R_60 ≥ 0.2 ○(0.30)
- 提案の稼働はしきい値の +10 ポイント以内 ○(+1.5〜+2.9)
- 境目(R_d が初めて 0.2 を超える d):**15 秒**。予想(15 秒は差なし、30 秒で 0.1〜0.3)より早かった
- 2 巡の値がほぼ同じ(差 10% 以内)で、再現性は良い。60 秒は open_delay60(11/26、R = 0.32)ともほぼ同じ

**注意**:提案は稼働が 1.5〜2.9 ポイント多い。同じ稼働で比べたときの差は実験 A(`20261127_tradeoff`、遅れ 60 秒)で見て、比 0.75〜0.90(1〜2.5 割減)だった。R_d の 3 割には、ファンを少し多く回した分も含まれる
