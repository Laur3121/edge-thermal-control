# model_check(熱モデルの形を確かめ直す、同定の長さ。オフライン)

実機の実験ではない。2026-11-28 夜。条件と判定は、この README を書いた時点(実行前)で決めた。結果は外れても書く。

## なぜやるか(本筋のどこか)

② と ③ の土台(予測と制御が使うモデル)。モデルの形(1 次遅れ + ファンの足し算、θ' = aθ + bu + ef + d)は 11/13 の同定実験で決めてから見直していない。レオ(11/28):「モデルが微妙なのでは。そのまま使い続けているので、もう一度ちゃんと確かめてほしい」。
また、`20261128_model_rack` で、同定した日と使う日で台ごとに数℃ずれることが分かった。同定が短くて済むなら、毎回(使う日に)同定すればよい(レオ)。どれくらい短くできるかも調べる。

## 方法

- データ(囲いなし、8 台とも HAT):
  - 同定:`20261126_open_ident` の前半 60%(台ごとにランダムな負荷 0〜3 コアとランダムなファン)
  - 評価 1(同じ日):`20261126_open_ident` の後半 40%
  - 評価 2(別の日):11/28 の `20261127_delay_sweep/d60`・`d30`・`20261127_tradeoff/d60`
- θ = T − 室温(ハブ 2)、5 秒ごと。スロットリング中を含む区間は除く。r5 は除く
- 指標:**実際の負荷とファンを与えて** 90 秒先(と 30 秒先)まで回したときの誤差の MAE(モデルそのものの再現の良さ。負荷が一定と仮定した予測とは別)
- 比べるモデルの形(台ごとに最小二乗)
  - **S1 今の形**:θ' = aθ + bu + ef + d
  - **S2 2 次**(チップとボードの 2 つの時定数):θ' = a₁θ + a₂θ₋₁ + bu + ef + d
  - **S3 ファンの効きが温度差に比例**:S1 + e₂ f θ
  - **S4 負荷が非線形**:S1 + b₂ u²
  - **S5 全部入り**:S2 + S3 + S4
- 同定の長さ:S1(と、一番良かった形)を open_ident の最初の 10・20・30・45 分(前半 60% は約 42 分)で同定し、評価 1 で比べる

## 判定(実行前に決めた)

- モデルの形:評価 1 と評価 2 の両方で、90 秒先の MAE が S1 の 0.8 倍以下 →「今の形より良い」。片方だけ →「はっきりしない」。どちらもだめ →「今の形で足りている」
- 同定の長さ:90 秒先の MAE が、一番長い同定の 1.1 倍以内に収まる一番短い長さを「足りる長さ」とする
- 「今の形より良い」形があれば、それを制御に入れる候補にする(入れる前に、check_params と同じ確認をする)

## 結果(2026-11-28 夜)

`check_models.py` → `results/forms.csv`・`length.csv`。7 台の平均:

| 形 | 90 秒先 MAE 同じ日 | 90 秒先 MAE 別の日 | 別の日の平均誤差 | 30 秒先 MAE 別の日 |
|---|---|---|---|---|
| S1 今の形 | 2.01 | 2.88 | +1.54 | 1.71 |
| S2 2 次 | 2.12 | 3.03 | +1.70 | 1.79 |
| S3 ファン × 温度差 | 1.88 | 3.38 | +2.51 | 2.08 |
| S4 負荷の非線形 | 2.18 | 3.09 | +0.47 | 1.84 |
| S5 全部入り | 2.15 | 3.20 | +1.39 | 1.94 |

- 判定:S2〜S5 のどれも「今の形で足りている」(同じ日・別の日の両方で 0.8 倍以下になるものはない。S3 は同じ日だけ 0.94)
- ただし、今の形でも、実際の入力を与えた 90 秒先の再現誤差が同じ日で 2.0℃ と大きい。形を変えても変わらないので、形より係数の決め方(1 ステップ先の最小二乗)を疑う
- 同定の長さ(S1、評価 1):10 分 3.44、20 分 2.40、30 分 2.13、42 分 2.08℃ → **足りる長さは 30 分**(42 分の 1.1 倍以内)。S3 も同じく 30 分

## 追加:係数を「90 秒先の再現誤差」が最小になるように決める(2026-11-28 夜、実行前に決めた)

- 今の係数は 1 ステップ(5 秒)先の誤差の最小二乗。制御で使うのは 90 秒先なので、90 秒先まで回したときの誤差(実際の入力を与える)の二乗和が最小になる係数を、数値最適化(scipy の least_squares、初期値は今の係数)で探す(S1 の形のまま。S1-M とする)
- 同定データ・評価は上と同じ
- 判定:評価 1・評価 2 の両方で 90 秒先の MAE が S1 の 0.8 倍以下 →「係数の決め方で良くなる」→ 制御に入れる候補。片方だけ →「はっきりしない」。どちらもだめ →「変わらない」

## まとめ(11/28 夜)

- モデルの形(2 次、ファン × 温度差、負荷の非線形、全部入り)と係数の決め方(90 秒先に合わせる)を試したが、どれも今の形・今の決め方より良くならなかった
- ただし今のモデルの再現の誤差は、実際の入力を与えても 90 秒先で約 2℃(負荷もファンも一定の区間でも 1.6℃)と大きい。ファンが切り替わる区間では、実際の方がモデルより 1.35℃ 冷える(ファンの効き始めがモデルより速い・強い)
- まだ試していない候補:ファンの効きに別の時定数を持たせる、温度センサの分解能、ステップ応答の形を直接見る
- 同定の長さは 30 分で足りる → 本番では使う日に 30 分の同定をする

## 追加 2:形を決めない高次のモデルで、取れる誤差の上限を見る(2026-11-28 夜、実行前に決めた)

- 目的:今のモデルの誤差(90 秒先 約 2℃)のうち、モデルの形を良くすれば取れる分がどれだけあるかを見る(レオ:「他にいい方法ないのかな」)
- **S6 高次 ARX**:θ' = Σ_{i=0..3} a_i θ_{t−i} + Σ_{j=0..11} (b_j u_{t−j} + e_j f_{t−j}) + d(過去 20 秒の温度、過去 60 秒の負荷とファン。29 個の係数)。最小二乗、同定・評価は上と同じ
- 判定:評価 1・評価 2 の両方で 90 秒先の MAE が S1 の 0.8 倍以下 →「形で取れる分がある」→ 物理の形(2 段の RC、ファンがヒートシンクの冷えやすさを変える)で説明しにいく。どちらもだめ →「形では取れない(今の形で限界に近い)」→ 実測で直す(KF、使う日の同定)と負荷リスクのマージンで受け持つ

### 追加 2 の結果

`check_arx.py` → `results/arx_high.csv`。7 台の平均:S1 同じ日 2.01・別の日 2.88℃、S6 同じ日 1.41・別の日 1.78℃(比 0.70・0.62)→ **形で取れる分がある**。
どの部分が効いているか(`check_arx_parts.py`、事後の分析):温度の過去だけ 2.07・3.05、ファンの過去だけ 1.94・2.97、**負荷の過去だけ 1.65・2.24**、負荷とファンの過去 1.44・1.89、全部 1.41・1.80。効いているのは過去 60 秒の負荷(と、それと合わせたファン)。

## 追加 3:2 段のモデル(チップとヒートシンク)(2026-11-28 夜、実行前に決めた)

- 考え:負荷の熱は、すぐ温まるチップと、ゆっくり温まるヒートシンク・ボードの 2 段で効く。ファンはヒートシンク側に効く。今のモデルは 1 つの温度で扱うので、負荷を変えた直後と、しばらく後の動きを同時に合わせられない
- **G2**:x₁ = チップ(測っている温度 θ)、x₂ = ヒートシンク(測っていない)
  x₁' = a₁₁x₁ + a₁₂x₂ + b₁u + e₁f + d₁、x₂' = a₂₁x₁ + a₂₂x₂ + b₂u + e₂f + d₂(10 個の係数)
  x₂ は、測った θ を入れて x₂ の式を回して求める(観測器)。先読みは x₁ = θ、x₂ = 観測器の値から 2 つを一緒に回す
- 係数は 90 秒先までの再現誤差が最小になるように数値最適化(初期値は S1 から)。同定・評価は上と同じ
- 判定:評価 1・評価 2 の両方で 90 秒先の MAE が S1 の 0.8 倍以下 →「2 段のモデルで物理として説明できる」→ KF と制御に入れる。S6 にどれだけ近いかも書く。だめなら S6(高次の ARX)をそのまま使うかを考える
