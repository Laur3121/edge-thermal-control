# stage_ident(囲いあり:ファンの段階ごとの効きの同定)

2026-11-26。条件は実行前(8:20)に決めた。生ログは編集しない。`20261126_box_control_simple` の後に `scripts/next_20261126.sh` が自動で始める。

## なぜやるか

ファンを 0/4 の 2 値でしか使っていなかった(レオの指摘:0→2、0→2→4 など)。段階を予測で選ぶ制御(`20261126_stage_ms`)には、段階ごとのファンの効きが要る。

## 条件

- 配置・囲い:昨夜から同じ。8 台とも PoE+ HAT
- 8 台に 2 コアの負荷を一定にかけたまま、ファン OFF 120 秒 → 段階 s で ON 240 秒 を、s = 1, 2, 3, 4, 4, 3, 2, 1 の順に(往復で温度の流れを打ち消す)。前に 5 分の慣らし(段階 4 で ON)
- シナリオ:`scripts/scenarios/gen_stage_ms.py ident` → `stage_ident.json`(約 1.1 時間)
- 同定:`scripts/fit_stage_eff.py`。θ_{t+1} = a θ + Σ e_s [段階 = s] + d、強制 ON・スロットリングを含む遷移は除く。相対的な効き eff_s = e_s / e_4 の 8 台の平均を、`scripts/control_params_box_ms.json` の各ノードに書く(ほかのパラメータは `control_params_box2.json`。11/26 8:40 に変更)
- 合成データでの確認:効き [0.3, 0.55, 0.8, 1] を [0.26, 0.53, 0.79, 1] と戻せた
- 予想(Claude):段階 1 は 0.2〜0.4、段階 2 は 0.5 前後、段階 3 は 0.8 前後

**実行前の変更(11/26 12:30、この実験の開始前)**:**囲いなしで行う**。レオの帰宅後に箱を外し、そのまま囲いなしで続けることにした(レオ「A でいい」:囲いありの制御データに、囲いなしの比較を加えるため)。パラメータは囲いなしで同定し直したもの(`scripts/control_params_open.json`:11/25 の囲いなしの測定 + `20261126_open_ident` の前半 6 割で同定し、後半 4 割で `check_params_holdout.py` を通したもの)を使う。囲いありのパラメータは流用しない。ほかの条件・判定・予想は変えない(予想は囲いありを前提に書いたので、外れても書く)。
