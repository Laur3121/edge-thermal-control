# edge-thermal-control

Raspberry Pi マイクロクラスタにおける、空間熱干渉を考慮した状態推定とファン制御による熱管理。
東京都立産業技術高等専門学校 専攻科 特別研究II(鈴木 黎映)。

## 概要

高密度に配置したシングルボードコンピュータでは、あるノードの排熱が隣のノードの温度を押し上げる(空間熱干渉)。
本研究では、この外部熱影響を時間変化する状態量としてモデル化し、カルマンフィルタで自ノード温度と同時に推定する。
推定の不確実性(誤差共分散)から安全マージンを動的に決め、予測温度が安全閾値を超えそうなときだけファンを回す。
目標は「スロットリングを避けながら、ファンをできるだけ回さない」こと。

前身:IPSJ 研究会発表(2026年4月)「空間熱干渉を考慮した状態推定に基づく動的熱マージン制御手法」。
当時のコードは残っていないため、予稿の式に基づいて再実装する。
