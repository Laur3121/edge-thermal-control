# IPSJ 研究会(2026年4月)で受けた質問・指摘

本人の記憶と、Notion「特研2」に残したメモから再構成(当時のメモそのものは残っていない)。

| 質問・指摘 | 特研IIでの対応 |
| --- | --- |
| この研究の意義は何か | エッジ環境は専用空調がなく高密度。干渉を推定して「必要なときだけファンを回す」ことで、スロットリング回避とファン稼働削減を両立する、と目的を具体化 |
| 小規模クラスタでやる意味は何か | 安価に実機で制御まで検証できる。手法は配置と隣接関係さえ分かれば大規模環境(ラック、スパコン)にも適用できる、と位置づける |
| 同じ環境で比較できているか | 室温を記録(SwitchBot 温湿度計2台)、各条件3回以上、条件の順番をランダム、開始時の温度をそろえる |
| 恒温室で実験してはどうか(提案) | 学校に恒温室はない。室温を記録して条件間のばらつきを示すことで代える。限界として論文に明記 |

## 発表後に本人が気づいた課題(2026-11 の見直し)

- 評価対象が負荷をかけたノードだったため、干渉の効果が見えにくかった
- 「負荷制御を発動」は実機に反映されておらず、ログに対するオフライン評価だった(実測は80℃を超えていた)
- 自ノード負荷の係数 b が負で、物理的に不自然
- 動的マージンの変動が小さく、固定マージンとの差が小さかった
- 実験は約20分×1回のみ、室温未記録
- 発表時の Kalman 実装コードが残っていない
