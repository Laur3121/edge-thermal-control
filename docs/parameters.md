## 自ノードの熱モデルの導出(5.2 の下書き)

RC モデル:C·dT/dt = −(T − T_amb)/R + P、 消費電力は負荷の一次式 P = P0 + k·u(u:CPU使用率 0〜1)。

刻み Δt の間 u を一定とみなして厳密に離散化すると(前進オイラーは Δt ≪ τ のときの近似):

```
T_{t+1} = a·T_t + b·u_t + d
a = exp(−Δt/τ),  τ = R·C
b = (1 − a)·R·k
d = (1 − a)·(T_amb + R·P0)
定常温度 T_∞ = T_amb + R·(P0 + k·u) = (b·u + d)/(1 − a)
```

→ a, b, d がすべて物理量に対応する。同定後に τ = −Δt/ln a を計算し、ステップ応答から直接読んだ時定数と一致するか確認する。

IPSJ で b が負になった原因の候補:u のスケール、a・d との多重共線性(負荷が長く一定の区間ばかりで、u が変化する場面が少ない)、温度が 84℃ で頭打ちになりモデルが成り立たない区間を含めた。→ 負荷 ON/OFF を含むステップ実験で、スロットリング前の区間だけを使って同定する。

## 干渉と H(5.3 の下書き)

```
H_{t+1} = ρ·H_t + (1 − ρ)·z_t,   z_t = T^nbr_t − z_base
T_{t+1} = a·T_t + b·u_t + c·H_t + d
```

H は隣の温度を一次遅れ(時定数 τ_H)で通したもの。ρ = exp(−Δt/τ_H)。
定常では H = z なので、隣が z だけ上がったときの自分の上昇は c·z/(1 − a)。
旧データでは隣(負荷側)が約 +32℃(52→84℃)、自分(アイドル)が約 +12℃ → c/(1 − a) ≈ 0.35〜0.4 が目安。

## ファンの効果(5.4、2026-11-13 案B に決定)

- 案A(切替モデル):ファン OFF / ON で (a, b, d) を別々に同定。ファンで R が下がる → τ が短くなり a が小さく、定常温度が下がる。物理的に自然
- 案B(加算項):T の式に + e·f_t(f_t = 0/1)。単純だが、ファンの効果が温度差に比例するという性質を表せない
- 決め方:同定データで両方の1ステップ・Δ秒先予測誤差を比べ、差が小さければ案A を採る(解釈しやすいため)。決めたらここと CLAUDE.md に書く

## 同定結果(2026-11-13)

詳細は `experiments/20261113_step_identify/README.md`。温度は**室温からの上昇分** θ = T − T_amb で扱う(実験中に室温が 1.6℃ 下がり、絶対温度のままだと約 1℃ ずれたため)。ファン ON 直後に数秒で数℃落ちる速い成分があり、1 次モデルでは表しきれない。案B の加算項がそれを近似している。
