# 式とパラメータの見直し(2026-11-26)

11/25 夜の囲いありの制御実験(`experiments/20261125_box_control`)で、予測を使う方式がどれも 80℃ を超えたのを受けて、モデルを見直した(レオ:「数式を見直す必要はなさそうなの?」)。

## 1. パラメータの誤り(見つかった、直した)

- `scripts/control_params_box.json`(11/25 午後の囲いありのデータで同定)は、ファンを回したデータが r2・r6 にしかなく、ほかの 6 台のファンの効き e を 2 台の定常の効きの平均(−29℃)から借りていた
- 昨夜の常時 ON(4 コア)の定常温度と比べると、借り物の 6 台はモデルが 10〜20℃ 低く見積もっていた(r5:モデル 56.6℃、実測 78.4℃)。自分で同定した r2・r6 は ±3℃
- 昨夜の 1 巡目で同定し、2 巡目で 30 秒先を評価すると(`scripts/eval_model_variants.py`、分け方は結果を見る前に決めた):

| モデル | 誤差 全体 | ファン ON | ファン OFF |
|---|---|---|---|
| A 昨夜の制御で使ったパラメータ | 4.28℃ | 6.13℃ | 2.73℃ |
| B 同じ式で同定し直す | 1.83℃ | 2.04℃ | 1.67℃ |
| C B + 隣のファンの項 g·f_nbr | 1.84℃ | 2.05℃ | 1.68℃ |

- **昨夜の制御で提案(と自ノードの予測)が負けた原因の一部は、手法ではなくパラメータの誤り**。ファン ON 中の推定がずれ、KF の状態(θ と H)が引きずられていた
- 直したもの:`scripts/control_params_box2.json`(11/25 午後 + 昨夜のデータを合わせて同定、`fit_control_params_box.py --exp ...`)。e は 8 台とも自分のデータ。ファン ON の定常温度は実測と 7 台で ±1℃(r4 は −3.7℃)
- 11/26 の d90 以降の実験はこれを使う(各 README の「実行前の変更」)。7:16 に始めた 2core は古いまま

## 2. 隣のファンの項(足さない)

- 11/25 夜の第 1 部で、下段のファンを回すと上段が 1〜2℃ 下がった(隣のファンの風が自分も冷やす)
- そこで θ の式に g·f_nbr(周りのノードのファンの平均)を足して比べたが、誤差は変わらず(上の C)、g の符号もノードによってばらばら(−1.03〜+0.53)
- → 式には足さない。風の効きは、ノードごとの位置(端か真ん中か、上か下か)に強く依存していて、平均のファンの状態では表せないと考えられる。12 月に、隣のファンだけを回す条件で直接測る

## 3. H の効き c が 0 になる(正直に書く)

- 合わせて同定すると、c は 8 台中 6 台で 0(c < 0 → 0 に制約)、r1 0.034、r8 0.090
- 昨夜は 8 台に同じ負荷パターンを同時にかけたので、「隣の温度」と「自分の負荷」が同じ動きをし、区別できない(多重共線性)。11/25 午後の(1 台ずつ負荷をかけた)データだけなら c は全台で正だった
- 予測精度の比較(`eval_pattern_pred.py`、11/25)で H が効いたのは、隣だけが動く区間を含むデータ。制御の評価で全台に同じ負荷をかけると、H の出番がない
- → 12 月:制御の評価でも、ノードごとに負荷をずらす(隣だけが熱くなる時間を作る)。それが「空間熱干渉を考慮した制御」の本来の評価条件

## 4. マージンが「ファンの余力」を見ていない(検討中)

- M = 2σ + 0.5 は予測の不確かさだけを見ている。囲いの中では、ファンを回し続けても 80℃ 付近までしか下がらない(余力がない)ので、温度が上がってから ON にしても戻らない
- 案:ファン ON のときの定常温度 θ_on = (b u + c H + e + d)/(1 − a) が Tlimit に近いときは、早めに ON にする(または OFF にしない)。今のモデルで計算できる
- 先読み Δ を長くする(d90)と、結果としてこれに近い動きになる。d90 の結果を見てから、式に入れるかを決める

## 5. ファンの段階

- ファンを 0/1 の 2 値で入れていた。段階を使うなら、効きを e × eff_s(eff_4 = 1)とする(`src/etc/control.py` の proposed_ms、`scripts/fit_stage_eff.py`)。段階ごとの効きは今夜の `20261126_stage_ident` で同定する
