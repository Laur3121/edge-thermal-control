# 予備審査で出すもの(先輩の資料から)

2026-11-13 に、2025年度の先輩2人(7305 小久保さん=田中研、7307 宮田さん=横井研)の予備審査資料を見て整理した。
資料そのものは本人の手元にあり、リポジトリには入れていない。ここには形式と分かったことだけを書く。

## 出すもの(4つ)

| もの | 形式 | 分量 | 先輩の例 |
| --- | --- | --- | --- |
| 発表資料(スライド) | PowerPoint、16:9、ページ番号「n / N」 | 17〜22枚 | 表紙 → 背景 → 目的 → 関連研究・既存手法の比較表 → 提案手法 → 実験 → 結果 → 考察 → まとめ |
| レジュメ | LaTeX(jsarticle 系)、A4、2段組み | 3〜4ページ | 特研1審査会のレジュメと同じ書式(下の「レジュメの書式」) |
| 成果の要旨 | 学校の様式(2a)「学修総まとめ科目 成果の要旨」。Word の表形式と思われる | **3ページ以内** | 下の「成果の要旨の項目」 |
| 論文 | LaTeX、A4、章ごとに改ページ | 宮田さんは予備審査の時点で36ページ(本文6章) | 表紙は下の「論文の表紙」 |

- 論文:規定では予備審査の時点で完成・40ページ以上。実際は毎年そこまでいかず、20ページ前後で出すのが定番(本人談)。知念研の先輩2人(7302、20260115)も論文を出しているので、**知念研では論文も出す**前提で準備する
- 日付:今年は **2026-11-27** で確定。去年(2025/12/5 ごろ)より1週間早い

## レジュメの書式

- 自分の特研1審査会のレジュメ(2025年度、`\documentclass[10pt]{jsarticle}`、余白20mm、`multicols*` で2段組み、fancyhdr)とほぼ同じ
- ヘッダー:左上「東京都立産業技術高等専門学校」、右上「創造工学専攻 情報工学コース」と「2025 年度特別研究 2 審査会」(宮田さん)、または「情報工学コース」と「2025 年度予備審査」(小久保さん)。色は紫系
- フッター:左下「Tokyo Metropolitan College of Industrial Technology」
- 表題部:題目、「番号 氏名」、「指導教員 ○○」を中央に
- 章立ての例:はじめに / 関連研究(または提案手法)/ 提案方式 / 実験・結果 / 考察 / まとめ(おわりに)/ 参考文献
- 図は段内または2段ぶち抜き。表は booktabs 風

## 成果の要旨の項目(様式2a)

冒頭の表:学校名、専攻名(創造工学専攻)、専攻分野名称(工学)、専攻の区分(情報工学)、氏名、学籍番号(8桁)、テーマ名、指導教員名、指導補助教員名

1. 「学修総まとめ科目」で取り組んだ学修・探究の内容
   - (1-1) 学修・探究の背景と目的
   - (1-2) 学修・探究の手法・方法
   - 倫理的配慮(先輩は2人とも「研究倫理委員会の対象となる研究計画はないため、該当なし」)
   - (1-3) 得られた結果と考察、将来展望(図・表を入れてよい)
   - 履修計画書から変更があった場合の理由、および履修計画書に対する評価・コメントへの対応
   - 参考文献
2. 「学修総まとめ科目」の学修・探究を支える学修全体について
   - (2-1) テーマの学修・探究の基盤となる専門科目の学修
   - (2-2) テーマの学修・探究に関係する関連科目の学修
   - (2-3) 専攻に係る科目以外の学修
   - (2-4) 自分自身の4年間の学修全体の省察

**自分の場合**:履修計画書は2026年春に提出したもの(本人談)。春の時点の内容と、今の方針(ファン制御が主、干渉は条件として評価)がずれていないかは、提出した計画書を見て確認する。ずれていれば「履修計画書からの変更」の欄に理由を書く。

## 先輩の資料から学べること

- 予備審査のスライド・レジュメは、**結果が1組あれば成立している**(小久保さん:サンプル画像2枚、宮田さん:データセット1つ)。全部の実験がそろっている必要はない
- 関連研究は**比較表**(○△×)で差分を見せると分かりやすい(小久保さんのスライド10)
- うまくいかなかった点を正直に「今後の課題」に書いている(小久保さん:丸め誤差で完全には復元できない)
