## 履修計画書(様式1a)の内容と、今とのずれ(2026-11-20、レオが PDF を共有)

成果の要旨の表と「履修計画書からの変更」の欄に使う。

- 学籍番号 25615016、指導教員 知念 賢一 教授、**指導補助教員 佐藤 喬 教授**
- 計画書のテーマ名:「エッジマイクロクラスタにおける空間熱干渉を考慮した熱抑制手法の研究」
- 授業科目名:特別研究II、課題名「次世代情報技術構築における情報基盤に関する基礎研究」
- 計画書の目的:干渉を状態として KF で推定 → 予測精度の向上と動的マージン。加えて、温度上昇が予測されるノードだけファンを動かし**消費電力を抑える**
- 計画書の方法:2 台 → ノード数を増やし、ノード間距離・配置パターンの影響を評価。**夏季(8〜9 月)の高外気温での評価**。冷却効果はファンなしとの比較と**消費電力**で評価。指標は MAE・RMSE・R²、制御発動割合・平均マージン・温度逸脱回数。比較は単一ノードモデルと誤差統計のマージン(坂本型)
- 今とのずれ(変更理由に書く):
  1. ラック・囲いなしでは干渉がほぼ出なかった → 主役が「干渉の推定」から「予測に基づくファン制御の実機評価」と「干渉が出る条件の線引き」へ
  2. ファンの電力は PoE 電流で区別できなかった → 減らす理由は寿命・騒音を主に(電力は大きなファンへの応用)
  3. 夏季の外気温評価は行っていない(室温を記録し、室温からの上昇分でモデル化することで代えた)
  4. 配置パターン・台数の拡張は予備審査の時点で 3 台・1 段まで。**12 月に 8 台で行う予定なので「変更」ではなく「途中」**(11/20 レオ:本番の発表は 1 月、副査は佐藤先生ともう一人、追加実験の期間が 1〜2 か月ある)
  5. 先行発表の評価の問題(未来の実測値、同定と評価が同じデータ)を直したので、指標・比較対象も変えた(閉ループのファン稼働率・80℃ 超過時間など)
- 実施計画書【個表】のキーワード(成果の要旨 (2-1)(2-2) の科目の候補):データ構造・言語処理とオートマトン・プログラミング特論I・II・オペレーティングシステム・ネットワーク工学特論I・II・エンジニアリングデザイン(専攻科1年)、プログラム設計法(本科5年)、アルゴリズムとデータ構造(本科4年)、コンピュータネットワークI・II(本科4・5年)、技術者倫理
